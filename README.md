# Clasificación de Patologías en Hojas de Tomate - PlantVillage

Proyecto de Técnicas avanzadas de machine learning enfocado en el preprocesamiento, análisis exploratorio de datos (EDA) y entrenamiento de un modelo (MLP) regularizado para la clasificación de imágenes agrícolas.

## Instrucciones de Ejecución
Para proteger las credenciales personales, este notebook descarga el dataset automáticamente conectándose a la API de Kaggle mediante los Secretos de Google Colab. 

Si desea ejecutar el código por su cuenta, siga estos pasos previos:
1. Obtenga su token de API desde La página oficial de Kaggle (https://www.kaggle.com/) 
2. En Google Colab, haga clic en el ícono de la llave en el panel lateral izquierdo.
3. Cree un nuevo secreto con exactamente el nombre: 'KAGGLE_KEY'
4. Adjunte el código alfanumérico de su token en la casilla de valor y active el interruptor *"Acceso desde el notebook"*.
5. Ejecute las celdas secuencialmente de arriba hacia abajo.
